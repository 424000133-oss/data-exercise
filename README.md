# Gaming Point Calculator

## Student Information

Name: Andrey Baylon O.
Section: BSIT

## Scenario

This program calculates a player's gaming points based on the number of wins, points earned per win, and bonus points. It also checks if the player reached the 100-point target.

## Data Types Used

- String - stores the player's name
- int - stores the number of wins
- double - stores points and bonus values
- bool - checks if the player reached the target

## Operators Used

- * - multiplication
- + - addition
- % - remainder
- >= - comparison

## How to Run

Run the program using:

dart run
